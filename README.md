## 🔄 Automatic Synchronization Setup

This repository is configured to receive automatic commits via:
1. **LeetHub v2 / v3 Chrome Extension**: Automatically commits code, runtime metrics, and problem statements on every "Accepted" submission.
2. **GitHub Action Sync Workflow**: Backfills past accepted solutions via `.github/workflows/leetcode-sync.yml`.
